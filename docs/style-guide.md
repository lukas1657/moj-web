# Dizajnová referencia

Táto príručka vychádza zo screenshotu úvodnej stránky Riverside. Uvedené farby sú vizuálne odhady, nie presné hodnoty zo zdrojového kódu.

## Vizuálny dojem

Čistý, moderný a sebavedomý SaaS dizajn s veľkým množstvom voľného priestoru. Rozhranie je prevažne monochromatické; výrazná fialová slúži ako akcent pre hlavné akcie. Jemný bodkovaný raster v pozadí dodáva stránke textúru bez toho, aby odvádzal pozornosť od obsahu. Používaj veľké, centrované nadpisy a jasnú vizuálnu hierarchiu.

## Farby

| Použitie | Odhad |
| --- | --- |
| Hlavné pozadie | `#F5F5F4` – veľmi svetlá, neutrálna sivobiela |
| Hlavný text a tmavé plochy | `#080808` – takmer čierna |
| Jemný bodkovaný raster | `#D5D5D5` |
| Povrch štítkov a svetlých prvkov | `#FAFAFA` |
| Sekundárne obrysy a ikony | `#969696` |
| Primárny akcent / hlavné CTA | `#8B68F5` – žiarivá levanduľová fialová |
| Text na tmavom alebo fialovom tlačidle | `#FFFFFF` |

Fialovú používaj striedmo, predovšetkým na primárne výzvy na akciu. Kontrast textu a pozadia má zostať vysoký.

## Typografia

- Použi moderné bezpätkové písmo s geometrickými tvarmi; vhodný základ je **Inter** alebo podobný neutrálne pôsobiaci sans-serif.
- Nadpisy sú veľké, ľahké až bežnej hrúbky a majú tesné riadkovanie. Hlavný nadpis môže byť na širokej obrazovke výrazne väčší než bežný text.
- Navigácia a podnadpisy používajú čitateľnú bežnú hrúbku; tlačidlá a značka môžu byť o niečo tučnejšie.
- Logo je kapitálkami, tučné a s mierne zväčšeným prekladom písmen.
- Zachovaj plynulé zmenšovanie veľkosti nadpisov a pohodlnú čitateľnosť na úzkych obrazovkách.

## Tlačidlá a ovládacie prvky

- Primárne CTA je široké, plné levanduľovo-fialové tlačidlo s bielym tučnejším textom a plne zaoblenými koncami.
- Sekundárne CTA v hlavičke používa čiernu výplň, biely text a rovnaký pilulkový tvar.
- Navigačné odkazy sú jednoduchý tmavý text bez výrazných dekorácií; rozbaľovacie položky dopĺňa malá šípka nadol.
- Výberové štítky majú svetlú výplň, jemné zaoblenie, tenký sivý obrys a nenápadný štvorcový indikátor.
- Medzi prvkami nechaj dostatok priestoru. Interakcie môžu pri hoveri jemne meniť odtieň alebo priehľadnosť bez výrazných tieňov.

## Rozloženie a detaily

- Hlavička je horizontálna, vzdušná, s logom vľavo, hlavnou navigáciou vedľa neho a odkazmi/CTA zarovnanými vpravo.
- Úvodná sekcia je centrovaná: výrazný dvojriadkový nadpis, krátky podnadpis, skupina štítkov a samostatné primárne CTA.
- Pozadie môže obsahovať pravidelný, veľmi jemný bodkovaný raster.
- Väčšie ukážky produktu alebo médií používajú tmavé plochy s mierne zaoblenými rohmi, čím vytvárajú kontrast so svetlým okolím.
- Pri menších šírkach zabaľ navigáciu a štítky, zmenšiť nadpis a zachovaj výraznú primárnu akciu.
